# JustOne

Admin control plane for a **personal** Jellyfin + Stremio stack.

1. Generate thousands of TRaSH-named `.strm` files (1080p and 4K trees).
2. Jellyfin plays a `.strm` → **resolver** asks CinePro for a working source → **HTTP 302** to that URL. Video bytes never pass through JustOne.
3. Raw Live TV M3Us remain available for IPTVEditor/VLC and compatibility.
4. A Jellyfin-native Live TV organizer generates a clean M3U + XMLTV guide, removes adult channels, collapses duplicate sports sources into failover slots, enriches channel metadata, and supplies programme artwork.
5. Optional Stremio addon: resolve, then give the player the **direct** URL.

> Personal / educational use only. You are responsible for what backends you connect and for applicable law.

## Deploy (Traefik + Let's Encrypt)

Path on the server: **`/opt/JustOne`**

- Host: **`resolver.vpn4u.cc`**
- Docker network: **`media_net`**
- TLS: Traefik cert resolver **`le`**

See [docs/traefik.md](docs/traefik.md).

```bash
cd /opt/JustOne
cp .env.example .env   # TMDB_API_KEY + secrets
docker compose up -d --build
sudo cp traefik/justone.yml /opt/traefik/dynamic/justone.yml
```

DNS for `resolver.vpn4u.cc` must point at this host.

| URL | Use |
| --- | --- |
| `https://resolver.vpn4u.cc/` | Admin |
| `https://resolver.vpn4u.cc/resolve/movie/{id}?quality=4k` | STRM target (302) |
| `https://resolver.vpn4u.cc/live/playlist.m3u8` | Raw IPTVEditor / VLC Live TV feed |
| `https://resolver.vpn4u.cc/jellyfin/playlist.m3u8` | Recommended Jellyfin Live TV tuner |
| `https://resolver.vpn4u.cc/jellyfin/guide.xml` | Recommended Jellyfin XMLTV guide |
| `https://resolver.vpn4u.cc/stremio/manifest.json` | Stremio |

If `PLAYLIST_KEY` is configured, append `?key=YOUR_KEY` to the Jellyfin tuner and XMLTV URLs. The M3U then emits keyed playback, guide and artwork URLs automatically.

## Jellyfin Live TV (recommended)

Use JustOne's dedicated Jellyfin feed instead of sending the raw M3U through an editor first:

1. Jellyfin → Dashboard → Live TV → **Tuner Devices** → add the M3U URL `/jellyfin/playlist.m3u8`.
2. Jellyfin → Dashboard → Live TV → **TV Guide Data Providers** → add the XMLTV URL `/jellyfin/guide.xml`.
3. Refresh guide data after changing the feed.

The organizer:

- excludes `18+` / adult channels by default;
- treats `Event — Broadcaster` rows as source candidates for one event instead of separate channels;
- ranks broadcaster sources and keeps backups for playback failover;
- maps simultaneous events onto reusable sport slots such as `Football 01`, `Tennis 01`, and `Basketball 01`;
- assigns stable Jellyfin-facing IDs, channel numbers and groups;
- uses IPTV-org channel metadata where a confident channel/country match exists, including logos and available XMLTV guide sources;
- merges XMLTV from `EPG_URL` and/or comma-separated `JELLYFIN_EPG_SOURCE_URLS` before automatic guide sources;
- generates fallback guide entries for unmatched channels so Jellyfin does not show `No information` everywhere;
- puts an XMLTV `<icon>` and backdrop image on generated programmes and serves local PNG artwork when no external artwork exists.

`cloud.iptveditor.com` is therefore optional. If you like its guide data, keep its **XMLTV** URL in `EPG_URL` or `JELLYFIN_EPG_SOURCE_URLS`; JustOne can merge that guide while doing the playlist organization itself.

Useful settings:

```env
JELLYFIN_AUTO_EPG=true
JELLYFIN_EPG_SOURCE_URLS=
JELLYFIN_EPG_MAX_SOURCES=12
JELLYFIN_EPG_CACHE_MIN=60
JELLYFIN_REFRESH_MIN=10
JELLYFIN_EXCLUDE_ADULT=true
```

The old `/live/*.m3u8` feeds are unchanged for clients that want the raw lineup.

## Libraries (TRaSH / Jellyfin)

On first start (and `POST /library/generate`) JustOne writes:

```text
/mnt/resolver-files/Movies/Movies/Title (Year) [tmdbid-123]/Title (Year) [tmdbid-123].strm
/mnt/resolver-files/Movies/Movies-4K/...
/mnt/resolver-files/TV/TV/Show (Year) [tvdbid-456]/Season 01/Show (Year) - S01E01.strm
/mnt/resolver-files/TV/TV-4K/...
/mnt/resolver-files/Live/playlist.m3u8
```

CinePro is not a catalog. Titles come from TMDB; at play the resolver asks CinePro for a working URL (all current providers) and 302s the player. The raw Live M3U is still generated by the platform; the Jellyfin Live service consumes and normalizes it.

Point four Jellyfin libraries at the four media folders. For Live TV, prefer the dedicated Jellyfin tuner and XMLTV URLs above.
